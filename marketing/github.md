## Description

Lint and diff Excel workbooks from the command line, CI or Python. Finds broken references, numbers typed over formulas, inconsistent formulas and links to other files, and shows what changed between two versions, following inserted rows. Text, JSON, SARIF and Markdown output. Runs locally.
